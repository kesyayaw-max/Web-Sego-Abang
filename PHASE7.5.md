# Phase 7.5 — UI/UX Redesign

A visual redesign focused on Pendopo Wonomarto's real restaurant identity.

## Goals
- Warm, modern, editorial restaurant aesthetic
- Consistent maroon / cream / brass visual language
- Original Pendopo Wonomarto logo used throughout the app
- Clear separation between customer-facing pages and staff/admin workflows
- Better forms, cards, buttons, tables, status badges, floor-map surfaces and mobile layouts
- No business logic or API contract changes

## Visual direction
- Primary: deep maroon
- Surface: warm cream / paper
- Accent: muted brass
- Typography: Fraunces + Plus Jakarta Sans
- Subtle shadows, borders and motion
- No excessive gradients, glassmorphism or decorative effects

## Main stylesheet
`frontend/assets/phase75-ui.css`

The stylesheet is loaded after page-specific styles so the redesign can improve the existing screens without rewriting their application logic.
