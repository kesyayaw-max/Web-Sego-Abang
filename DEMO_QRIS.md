# Demo QRIS

Project ini saat ini menggunakan QRIS DEMO untuk keperluan presentasi/testing.

- QR code demo **bukan alat pembayaran nyata**.
- Pembayaran tetap berstatus `PENDING` sampai admin melakukan konfirmasi manual.
- Setelah client memberikan QRIS merchant resmi, upload/ganti URL gambar QRIS melalui **Admin > Pengaturan > QRIS & Pembayaran**.
- Untuk automatic payment verification, integrasikan acquirer/PJSP QRIS yang menyediakan API/webhook.
